# Proposed project license: MIT

**Status: proposal only.** The repository does not yet have a project-wide license. Do not treat this draft as permission to redistribute PixelForge. Maintainers must approve the license and confirm the copyright holder before creating the root `LICENSE` file or publishing a public release.

MIT is a short permissive license that allows use, modification, distribution, sublicensing, and sale, provided the copyright and permission notice stays with copies or substantial portions. It disclaims warranties and liability. Choosing it means PixelForge source can be reused in proprietary projects; it does not change the separate licenses for SDL3, Dear ImGui, nlohmann/json, stb, or the CC0 atlas. The project owner should confirm that all contributions can be offered under the selected terms.
